# ADR-001 Core vs Product Separation

Status: ACCEPTED
Owner: graph-memory-core
Date: 2026-08-20

Context
Graph Memory Core is private infrastructure layer. CareerGraph is open source product.
This separation was established in CareerGraph Core Principles v14 and validated through architecture audit.

Decision
Core provides storage, events, runtime. Product provides domain model, UI, workflows.
The boundary between core and product ensures generic engine can support multiple domains.

Consequences
- Core changes must not expose product-specific concerns
- Product must not depend on core internals beyond public API
- Multiple products can share the same core engine
