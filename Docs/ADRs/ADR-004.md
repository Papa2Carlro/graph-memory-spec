# ADR-004 Graph Language Human-First Philosophy

Status: ACCEPTED PRINCIPLE
Owner: graph-memory-language
Date: 2026-08-20

Context
Graph Language designed for human authorship first, machine processing second. Language should be readable and writable by humans.

Decision
- Language syntax optimized for human readability
- Compiler handles optimization
- Domain experts can write directly
- Machine-readable but human-first

Consequences
- Graph Language is accessible to non-programmers
- Compiler bridges human syntax to machine requirements
- Requires tooling (formatter, linter) for production use
