# ADR-009 Graph Commit Model

Status: ACCEPTED PRINCIPLE
Owner: graph-memory-core
Date: 2026-08-20

Context
Graph supports commit-based history similar to Git. Snapshots enable diff and evolution tracking.

Decision
- Graph Commit = snapshot checkpoint
- Enables graph diff
- Tracks evolution
- Career evolution visible

Consequences
- Graph evolution is visible and auditable
- Diffs enable understanding of changes over time
- Supports rollback and replay of graph history
