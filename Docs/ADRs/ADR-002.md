# ADR-002 File Format - .gmem vs .cgraph

Status: ACCEPTED
Owner: graph-memory-core
Date: 2026-08-20

Context
.gmem is generic Graph Memory Core format. .cgraph domain-specific format should be deprecated to avoid conflation.

Decision
- .gmem = Graph Memory Core storage format
- .cgraph → domain-specific or deprecated
- Core knows generic format, domains map to it

Consequences
- .gmem files are portable between installations
- .cgraph files require migration for continued use
- Domains must map their format to .gmem for core compatibility
