# ADR-003 Two-Level MCP Architecture

Status: ACCEPTED
Owner: graph-memory-mcp
Date: 2026-08-20

Context
MCP tools split into core layer (graph operations) and domain layer (application tools).

Decision
Graph Memory Tools (core)
        |
        ↓
Domain Tools (CareerGraph)

Core tools: graph query, create, update, snapshot
Domain tools: career workflows, vacancy matching, etc.

Consequences
- Core tools are generic, domain tools are specific
- Domain tools depend on core tools, not vice versa
- Clear separation enables independent evolution
