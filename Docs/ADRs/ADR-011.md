# ADR-011 Repo Structure Proposal

Status: ACCEPTED
Owner: careerhub
Date: 2026-08-20

Context
Ecosystem split into core, language, MCP, CLI, spec, and product repos.

Decision
- graph-memory-core: engine
- graph-memory-language: compiler
- graph-memory-mcp: integration
- graph-memory-cli: tooling
- graph-memory-spec: public specs
- careerhub: product

Consequences
- Clear repo ownership and boundaries
- Enables independent versioning
- Supports multiple products sharing core
