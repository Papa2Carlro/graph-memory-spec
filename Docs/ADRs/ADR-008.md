# ADR-008 Agent Permission Model

Status: ACCEPTED
Owner: graph-memory-mcp
Date: 2026-08-20

Context
Agents defined as entities with read/propose/execute permissions. Agent execution via MCP to external AI model.

Decision
- Agent = Entity with permissions
- Permissions: read/propose/execute
- Execution via MCP to external AI
- Agent actions audited

Consequences
- Clear permission model enables agent accountability
- MCP integration provides centralized control
- Auditing supports compliance and debugging
