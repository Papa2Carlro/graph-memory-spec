# ADR-006 Portability Requirements

Status: ACCEPTED
Owner: graph-memory-core
Date: 2026-08-20

Context
Graph files must be portable between CareerGraph installations. File format self-contained.

Decision
- .gmem files portable
- Schema embedded in file
- No external dependencies
- Can migrate between installations

Consequences
- Files can be shared across installations
- No runtime dependencies on specific CareerGraph version
- Enables distributed collaboration
