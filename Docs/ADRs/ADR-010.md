# ADR-010 Rules vs Workflows Separation

Status: ACCEPTED
Owner: graph-memory-core
Date: 2026-08-20

Context
Rules are reactive (event → state change). Workflows are orchestration (sequence of actions). Separate engines.

Decision
- Rules engine: reactive
- Workflows engine: orchestration
- Separate concerns

Consequences
- Reactive rules respond to events immediately
- Orchestration workflows manage complex sequences
- Clear separation enables independent scaling
