# ADR-005 Event Sourcing Model

Status: ACCEPTED
Owner: graph-memory-core
Date: 2026-08-20

Context
Graph is projection from event stream, not direct database. Events are source of truth.

Decision
Event Stream
      ↓
Graph Projection
      ↓
Current State

Events: SkillCreated, ProjectCreated, EvidenceAdded, DecisionRecorded, RelationshipCreated

Graph is projection, not persistence.

Consequences
- All changes recorded as events
- Graph state is projection, not persistent store
- Enables time-travel and audit capabilities
